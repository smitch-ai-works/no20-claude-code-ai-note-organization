## 手順

1. ユーザーに「今回のテーマ」を一言で聞く（未指定なら質問してから進める）
2. researcher エージェントを呼び出し、テーマをリサーチさせる
3. リサーチ結果を writer エージェントに渡し、記事本文を作らせる
4. 完成した記事本文を title-maker エージェントに渡し、タイトル案を3つ出させる
5. 記事本文を proofreader エージェントに渡し、チェック・修正させる
6. 修正済みの記事本文を marketer エージェントに渡し、要約とSNS告知文を作らせる
7. 最終的に「タイトル案3つ」「記事本文（校正済み）」「SNS告知文」をまとめてユーザーに提示する

## 注意
- 各エージェントには、それぞれの専門範囲だけを渡す（余計な指示を混ぜない）
- ユーザーから「〇〇担当だけやり直して」と言われたら、該当のエージェントだけ再実行する
